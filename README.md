# JAMTRAC Inc.

Phase 1 of the JAMTRAC Inc. website is a clean, static website foundation.

## Architecture

The site uses only HTML5, CSS3, vanilla JavaScript, and static assets. All deployable files are in `/public`; there are no runtime dependencies, build tools, server-side components, APIs, or Worker configuration.

## Cloudflare Pages deployment

- Build command: none
- Build output directory: `public`

Deploy the repository directly with Cloudflare Pages. No compilation step is required.
